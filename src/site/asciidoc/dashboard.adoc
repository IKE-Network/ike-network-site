= IKE Dashboard
:icons: font
:download: https://github.com/IKE-Network/ike-dashboard/releases/latest/download/IKE-Dashboard-osx-aarch64.zip

The IKE Dashboard is one window for working with Komet. It keeps Komet
versions installed side by side and current, keeps the knowledge bases in
`~/Solor` current, and opens any knowledge base in any Komet version as an
independent application. Its first screen, *Notices*, lists what needs
attention, each with one action: a newer build of a knowledge base, work
not yet committed, a newer Komet.

== Download

{download}[*Download the IKE Dashboard*] for a Mac with Apple silicon.

The link always fetches the newest version. The application is signed
with IKE's Developer ID and notarized by Apple, so macOS opens it without
warnings.

== Install

. Open the downloaded `IKE-Dashboard-osx-aarch64.zip` to unzip it.
. Move *IKE Dashboard.app* into your Applications folder.
. Open it from there.

From then on the dashboard updates itself. When a newer version is
published, the Notices screen offers it; *Update and restart* downloads
it, checks it, and restarts the dashboard on it. Komets that are running
are not affected.

If you open the dashboard straight from the Downloads folder, macOS runs
it from a read-only copy, and it cannot update itself there. Its first
notice then offers to move it into your Applications folder.
