= IKE Dashboard
:icons: font
:download-mac: https://github.com/IKE-Network/ike-dashboard/releases/latest/download/IKE-Dashboard-osx-aarch64.pkg
:download-windows: https://github.com/IKE-Network/ike-dashboard/releases/latest/download/IKE-Dashboard-windows-x86_64.msi

The IKE Dashboard is one window for working with Komet. It keeps Komet
versions installed side by side and current, keeps the knowledge bases in
`~/Solor` current, and opens any knowledge base in any Komet version as an
independent application. Its first screen, *Notices*, lists what needs
attention, each with one action: a newer build of a knowledge base, work
not yet committed, a newer Komet.

== Download

* {download-mac}[*Download the IKE Dashboard for Mac*] (Apple silicon)
* {download-windows}[*Download the IKE Dashboard for Windows*] (64-bit)

Each link always fetches the newest version. Both are installers, as
Komet's are.

== Install

=== Mac

. Open the downloaded `IKE-Dashboard-osx-aarch64.pkg`.
. Follow the installer. It puts *IKE Dashboard* in your Applications
  folder.
. Open it from there.

The installer is signed with IKE's Developer ID and notarized by Apple,
so macOS opens it without warnings.

=== Windows

. Open the downloaded `IKE-Dashboard-windows-x86_64.msi`.
. Follow the installer. It installs the dashboard for you alone, with no
  administrator password, and adds *IKE Dashboard* to the Start menu.
. Open it from the Start menu.

The Windows installer is not signed yet, so Windows SmartScreen may say
_Windows protected your PC_. Choose *More info*, then *Run anyway*.

== Updates

From then on the dashboard updates itself. When a newer version is
published, the Notices screen offers it; *Update and restart* downloads
it, checks it, and restarts the dashboard on it. Komets that are running
are not affected.
